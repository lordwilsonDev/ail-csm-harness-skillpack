# Skill 20 — Final Synthesis, Evidence Ledger & Release Gate
## Goal
Assemble the deliverable and make its verification status truthful.

## Procedure
- Integrate only claims with verified support or explicit qualification.
- Attach evidence IDs/citations to material claims.
- Include assumptions, unknowns, counterarguments, calculations, and limitations.
- Reconcile the artifact with the requirements matrix and defect log.
- Set release status using the meta-skill gates.
- State exactly what was and was not verified.

## Output
1. Final artifact.
2. Evidence ledger.
3. Assumptions/unknowns register.
4. Defect log.
5. Release status and rationale.
6. Reproduction steps.

## Fail conditions
Any critical defect remains while status is FINAL-READY; evidence status is overstated; or required audit trail is absent.
