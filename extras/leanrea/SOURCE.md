What it is: one small skill file that teaches an AI to reverse engineer shipped software (apps, binaries, APKs, packet captures) using plain command-line tools.

Use it only on software you own or have permission to analyze, and follow the license terms of what you inspect.
The benchmark numbers in the author's README are the author's own (3 runs per test, one model, one machine). We have not re-run them.
