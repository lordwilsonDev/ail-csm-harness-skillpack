# Skill 03 — Artifact Requirements Extraction
## Goal
Create a traceable map from requested components to evidence and tests.

## Procedure
- Enumerate structural, substantive, citation, calculation, and format requirements.
- Give every requirement an ID and an acceptance test.
- Map each requirement to planned section(s), inputs, and verification skill.
- Detect contradictory or impossible requirements.

## Output
Requirements traceability matrix: ID | requirement | planned location | test | status.

## Fail conditions
Any required element lacks a location or test.
